# 12.3.2 - Нахождение наибольшего делителя.

НОД двух положительных целочисленных **x** и **y** определяется следующим образом:
- Если **x** можно разделить на **y** без остатка, то **gcd(x, y) = y**. Данное условие является базовым случаем.
- В противном случае **gcd(x, y) = gcd(y, остаток от деления x/y)**.

Программа gcd.py демонстрирует это.

## gcd.py
> Код рекурсии [gcd.py](gcd.py).
```python
# Программа применяет рекурсию для нахождения
# НОД двух чисел


def main():
    # Получить два числа
    num1 = int(input("Введите целое число: "))
    num2 = int(input("Введите целое число: "))

    # Показать НОД
    print(f"Наибольший общий делитель\n" f"этих двух числе равен {gcd(num1, num2)}.")


# Функция возвращает НОД
# двух чисел
def gcd(x, y):
    if x % y == 0:
        return y
    else:
        return gcd(x, x % y)


if __name__ == "__main__":
    main()
```
Вывод:
```
Введите целое число: 15
Введите целое число: 3
Наибольший общий делитель
этих двух числе равен 3.
```
