# 12.3.1 - Последовательность Фибоначчи.
Данная последовательность представляет собой сумму предыдущих чисел для последующего числа.

Она может быть определена следующим образом:
- Если n = 0 -> Fib(n) = 0;
- Если n = 1 -> Fib(n) = 1;
- Если n > 0 -> Fib(n) = Fib(n - 1) + Fib(n - 2).

Сама же функция выглядела бы так:
```python
def fib(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fib(n - 1) + fib(n - 2)
```
Программа **fibonacci.py** демонстрирует это.

## fibonacci.py
> Код рекурсии [fibonacci.py](fibonacci.py).
```python
# Программа применяет рекурсию для печати чисел
# последовательности Фибаначчи


def main():
    print("Первые 10 чисел")
    print("последовательности Фибаначчи:")

    for number in range(1, 11):
        print(fib(number))


# Функция возврщает n-ое число
# последовательности Фибоначчи
def fib(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fib(n - 1) + fib(n - 2)


if __name__ == "__main__":
    main()
```
