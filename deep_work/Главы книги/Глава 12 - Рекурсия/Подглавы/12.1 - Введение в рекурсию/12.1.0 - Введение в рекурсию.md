# 12.1.0 - Введение в рекурсию.

**Рекурсивная функция** - это функция вызывающая саму себя.

Пример такой функции в программе **endles_recursion.py**.
## endles_recursion.py
> Код рекурсии [endles_recursion.py](endles_recursion.py).
```python
# Программа демонстрирует рекурсивную функцию

def main():
    message()

def message():
    print('Это рекурсивная функция')
    message()

if __name__ == '__main__':
    main()
```
Вывод:
```
Это рекурсивная функция
Это рекурсивная функция
Это рекурсивная функция
Это рекурсивная функция
Это рекурсивная функция
Это рекурсивная функция
Это рекурсивная функция
Это рекурсивная функция
...
Traceback (most recent call last):
RecursionError: maximum recursion depth exceeded
```
Как видно, функция **message()** вызывает себя, является рекурсивной и выполняется бесконечное кол-во(В примере оно вызывает исключение из-за заполнения окна рекурсии).

Как и в цикле, рекурсия должна иметь способ управлять кол-вом своих повторов. Для этого введем переменную, через которую будем отслеживать кол-во циклов рекурсии.

## recursive.py
> Код рекурсии [recursive.py](recursive.py).
```python
# Программа демонстрирует рекурсивную функцию

def main():
    # Передаем аргументом 5 в функцию
    # мы сообщаем ей, что нужно показать сообщение
    # 5 раз
    message(5)

def message(times):
    if times > 0:
        print('Это рекурсивная функция')
        message(times - 1)

if __name__ == '__main__':
    main()
```
Вывод:
```
Это рекурсивная функция
Это рекурсивная функция
Это рекурсивная функция
Это рекурсивная функция
Это рекурсивная функция
```
Инструкция if управляет повторением, пока значение times будет > 0, будет происходить рекурсия. Данное условие управляет глубой рекурсии.
