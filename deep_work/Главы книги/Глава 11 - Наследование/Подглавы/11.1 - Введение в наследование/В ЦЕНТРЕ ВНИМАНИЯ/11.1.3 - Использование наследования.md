# 11.1.3 - Использование наследования.

Необходимо разработать объектно-ориентировнаную систему, которая управляет клиентскими банковскими счетами. Необходимо спроектировать класс, который представляет собой сберегательный счет. Вот данные, которые должен содержать объект этого класса:
- Номер счета;
- Процентная ставка;
- Остаток счета.

Так же необходимо разработать класс, который представляет счет депозитного сертификата. Вот данные, которые должен содержать объект этого класса:
- Номер счета;
- Процентная ставка;
- Остаток счета;
- Дата погашения счета.

Анализируя ТЗ, понимаем, что счет депозитного сертификата является конкретизированным вариантом сберегательного счета, т.е является подклассом.
Для выполнения задачи, разработаем надкласс SavingsAccount, для представления сберегательного счета, и подкласс CD для представления счета депозитного сертификата.

## Класс SavingsAccount
> Код класса [accounts.py](accounts.py).
```python
# Класс SavingsAccount представляет
# сберегательный счет.


class SavingsAccount:

    # Инициализируем атрибуты класса, принимающенго
    # номер счета, процентной ставки и баланс
    def __init__(self, account_num, int_rate, bal):
        self.__account_num = account_num
        self.__int_rate = int_rate
        self.__balance = bal

    # Ниже методы-мутаторы атрибутов данных
    def set_account_num(self, account_num):
        self.__account_num = account_num

    def set_int_rate(self, int_rate):
        self.__int_rate = int_rate

    def set_bal(self, bal):
        self.__balance = bal

    # Методы-получатели атрибутов данных
    def get_account_num(self):
        return self.__account_num

    def get_int_rate(self):
        return self.__int_rate

    def get_bal(self):
        return self.__balance
```

Класс является надклассом, он имеет атрибуты данных для номера счета, процентной ставки и текущего остатка на балансе. Так же имеет методы-мутаторы и методы получатели. После него проектируем надкласс CD:

### Подкласс CD
---
> Код подкласса [accounts.py](accounts.py).
```python
# Класс CD представляет счет
# депозитного сертификата(CD).
# Это подкласс класса SavingsAccount


class CD(SavingsAccount):

    # Инициализируем аргументы для номера счета, процентной ставки, 
    # баланса и даты погашения 
    def __init__(self, account_num, int_rate, bal, mat_date):
        # Вызвать метод init надкласса SavingsAccount
        SavingsAccount.__init__(self, account_num, int_rate, bal)
        # Инициализировать атрибут __maturity_date
        self.__maturity_date = mat_date

    # Метод set_maturity_date является методом-мутатором
    # атрибута __maturity_date
    def set_maturity_date(self, mat_date):
        self.__maturity_date = mat_date

    # Метод get_maturity_date является методом-получателем
    # атрибута __maturity_date
    def get_maturity_date(self):
        return self.__maturity_date
```
Подкласс принимает надкласс **SavingsAccount** с его атрибутами данных, инициализирует их и свой атрибут данных **__maturity_date**. Так же имеет методы-мутаторы и методы получатели.

После написания надкласса и подкласса пишем саму программу, которая будет их использовать

## accounts_demo.py
> Код программы [accounts_demo.py](accounts_demo.py).
```python
# Программа создает экземляр класса SavingsAccount
# и экземпляр CD

import accounts


def main():
    # Получаем номер счета, процентную ставку
    # и остаток сберегательного счета
    print("Введите данные о сберегательном счета.")
    acct_num = input("Номер счета: ")
    int_rate = float(input("Процентная ставка: "))
    balance = float(input("Остаток: "))

    # Создаем объект SavingsAccount
    savings = accounts.SavingsAccount(acct_num, int_rate, balance)

    # Получаем номер счета, процентную ставку,
    # остаток сберегательного счета и дату погашения счета CD
    print("Введите данные о счете CD.")
    acct_num = input("Номер счета: ")
    int_rate = float(input("Процентная ставка: "))
    balance = float(input("Остаток: "))
    maturity = input("Дата погашения: ")

    # Создаем объект CD
    cd = accounts.CD(acct_num, int_rate, balance, maturity)

    # Показать введенные данные
    print("Вот введенные Вами данные:")
    print()
    print("Сберегательный счет")
    print("-------------------")
    print(f"Номер счета: {savings.get_account_num()}")
    print(f"Процетная ставка: {savings.get_int_rate()}")
    print(f"Остаток: ${savings.get_bal()}")
    print()
    print("Счет депозитного сертификата (CD)")
    print("---------------------------------")
    print(f"Номер счета: {cd.get_account_num()}")
    print(f"Процетная ставка: {cd.get_int_rate()}")
    print(f"Остаток: ${cd.get_bal()}")
    print(f"Дата погашения: {cd.get_maturity_date()}")


if __name__ == "__main__":
    main()
```
В программе демонстрируется пример использования надкласса вместе с подклассом
