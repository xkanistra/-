# 11.1.1 - Наследование и отношение 'род - вид'.

**Отношение "род - вид"** или **отношение классификации** - это когда один объект является конкретизированным вариантом другого объекта.

Например:
- Автомобиль - это вид автотранспортного средства;
- Цветок - это вид растения;
- Прямоугольник - это вид геометрическиой фигуры;
- Футболист - это вид спортсмена.

Когда возникает такое отношение это означает, что конкретизированный объект имеет все свойства родового объекта плюс свои дополнительный свойства (как например кузнечик прыгает, а шмель жалит).

В **ООП** наследование используется для создания **отношение "род - вид"** среди классов. Это позволяет расширять возможности класса путем создания другого класса, являющегося конкретизированным вариантом.

Наследование связанно с существованием **надкласса** и **подкласса**.
1. **Надкласс** - это родовой класс;
2. **Подкласс** - это конкретизированный класс, его можно представить, как расширенный вариант надкласса.

**Подкласс** наследует атрибуты и методы **надкласса** без необходимости переписывать их, помимо этого в подкласс могут быть добавлены новые атрибуты и методы - именно это и делает его конкретизированным вариантом класса.

## Пример демонстрации наследования.
Например нужно написать ПО для автосалона, который продает автомобили. В их ассортименте представлены следующие типы машин:
1. Легковые автомобили;
2. Пикапы;
3. Джипы.

Независимо от типа авто, они поддерживают следующие данные:
- Фирма-изготовитель;
- Модель указанного года выпуска;
- Пробег;
- Цена.

Каждый авто имеет выше представленные данные, плюс свои дополнительные данные:
- Легковой автомобиль: число дверей(2 или 4);
- Пикап: тип привода (монопривод или полный привод);
- Джип: пассажирская вместимость.

Один из подходов состоит в написании 3 отдельных классов:
- **Car**: легковые авто;
- **Truck**: пикапы;
- **SUV**: джипы.

Однако такой подход мало эффективен, т.к было бы много повторения одних и тех же атрибутов которые общие для всех 3 классов.

Оптимальный подход состоит в написании надкласса **Automobile**, который будет содержать все общие данные о автомобиле, а затем написать подклассы для каждого конкретного вида автомобиля.

> Код класса [automobile.py](automobile.py).

automobile.py
---
```python
# Класс Automobile содержит общие данные
# об автомобилях на складе


class Automobile:
    # __init__ принимает аргументы для
    # фирмы-изготовителя, модели, пробега и цены.
    # Он инициализирует атрибуты этих значений

    def __init__(self, make, model, mileage, price):
        self.__make = make
        self.__model = model
        self.__mileage = mileage
        self.__price = price

    # Создание методов которые являются мутаторами
    # атрибутов этого класса

    def set_make(self, make):
        self.__make = make

    def set_model(self, model):
        self.__model = model

    def set_mileage(self, mileage):
        self.__mileage = mileage

    def set_price(self, price):
        self.__price = price

    # Создание методов которые получателями
    # атрибутов этого класса.

    def get_make(self):
        return self.__make

    def get_model(self):
        return self.__model

    def get_mileage(self):
        return self.__mileage

    def get_price(self):
        return self.__price
```
Данный класс является законченным, и его можно импортировать в любую программу как модуль. Однако он не имеет конкретной информации о видах авто, для это в модуле напишем подклассы которые будут наследовать надкласс  **Automobile**.

> Код подкласса **Car** представлен в [automobile.py](automobile.py):
```python
# Класс Car представляет легковой автомобиль.
# Он является подклассом класса Automobile.


class Car(Automobile):
    # __init__ принимает аргументы для
    # фирмы-изготовителя, модели, пробега и цены.
    # Он инициализирует атрибуты этих значений

    def __init__(self, make, model, mileage, price, doors):
        # Вызываем метод __init__ надкласса и передаем
        # требуемые аргументы. Так же мы передаем self в
        # качестве аргумента.
        Automobile.__init__(self, make, model, mileage, price)
        self.__doors = doors

    # Метод является методом-мутатором атрибута __doors
    def set_doors(self, doors):
        self.__doors = doors

    # Метод является методом-получателем атрибута __doors
    def get_doors(self):
        return self.__doors
```
Строка:
```python 
class Car(Automobile):
``` 
говорит о том, что мы определяем подкласс Car и он наследует от надкласса Automobile его атрибуты, а так же **self** в строке:
```python
def __init__(self, make, model, mileage, price, doors):
    Automobile.__init__(self, make, model, mileage, price)
```
затем в строке:
```python
self.__doors = doors
```
инициализируется атрибур подкласса **Car**. Данное используется всегда, когда нужно создать подкласс какого-либо надкласса.

Далее рассмотрим создание подкласса **Truck**(его создание ничем не отличается от создания подкласса Car, логика такая же).

> Код подкласса **Truck** представлен в [automobile.py](automobile.py):
```python
class Truck(Automobile):
    # __init__ принимает аргументы для
    # фирмы-изготовителя, модели, пробега и цены.
    # Он инициализирует атрибуты этих значений

    def __init__(self, make, model, mileage, price, drive_type):

        # требуемые аргументы. Так же мы передаем self в
        # качестве аргумента.
        Automobile.__init__(self, make, model, mileage, price)
        self.__drive_type = drive_type

    # Метод является методом-мутатором атрибута __drive_type
    def set_doors(self, drive_type):

    # Метод является методом-получателем атрибута __drive_type

        return self.__drive_type    
```
Тут наглядно видно, что подкласс **Truck** создается по тому же принципу, что и подклаcc **Car**.

Теперь продемонстрируем работу надкласса и подклассов в программе car_truck_suv_demo.py.
> Код представлен в [car_truck_suv_demo.py](car_truck_suv_demo.py):

car_truck_suv_demo.py
---
```python
# Программа создает объекты Car, Truck, SUV

import automobile


def main():
    # Создаем объект Car для авто BMW 2001 года
    # с 70000 милями пробега, ценой 15000.00$ и 4 дверьми
    car = automobile.Car("BMW", 2001, 70000, 15000.00, 4)

    # Создаем объект Truck для авто Toyota 2002 года
    # с 40000 милями пробега, ценой 1200.00$ и полным приводом
    truck = automobile.Truck("Toyota", 2002, 40000, 12000.00, "4WD")

    # Создаем объект SUV для авто Volvo 2000 года
    # с 30000 милями пробега, ценой 18500.00$ и вместимостью 5 человек
    suv = automobile.SUV("Volvo", 2000, 30000, 18500.00, 5)

    print("ПОДЕРЖАННЫЕ АВТО НА СКЛАДЕ")
    print("==========================")

    # Показать данные легковое авто
    print("Данный легковой автомобиль имеется на складе.")
    print(f"Изготовитель: {car.get_make()}")
    print(f"Модель: {car.get_model()}")
    print(f"Пробег: {car.get_mileage()}")
    print(f"Цена: {car.get_price()}")
    print(f"Количество дверей: {car.get_doors()}\n")

    # Показать данные пикапа
    print("Данный легковой автомобиль имеется на складе.")
    print(f"Изготовитель: {truck.get_make()}")
    print(f"Модель: {truck.get_model()}")
    print(f"Пробег: {truck.get_mileage()}")
    print(f"Цена: {truck.get_price()}")
    print(f"Тип привода: {truck.get_drive_type()}\n")

    # Показать данные джипа
    print("Данный легковой автомобиль имеется на складе.")
    print(f"Изготовитель: {suv.get_make()}")
    print(f"Модель: {suv.get_model()}")
    print(f"Пробег: {suv.get_mileage()}")
    print(f"Цена: {suv.get_price()}")
    print(f"Пассажирская вместимость: {suv.get_pass_cap()}\n")


if __name__ == "__main__":
    main()
```
