# 11.2.0 - Полиморфизм.
**Полиморфизм** - это способность объекта принимать различные формы. Эта способность является мощным механизмом ООП.

Рассмотрим два важнейших компонента полиморфизма:
- Возможность определять метод в надклассе и затем определять метод с тем же именем в подклассе. В данном случае говорят: *"Метод подкласса **переопределяет** метод надкласса"*
- Возможность вызывать правильный вариант переопределенного метода в зависимости от типа объекта, который используется для его вызова. Т.е. если объект подкласса используется для вызова переопределенного объекта, то вызовется вариант метода подкласса, если вызовется вариант надкласса, то вызовется вариант метода надкласса.

Рассмотрим пример полиморфизма на примере класса **Mammal** в модуле **animals.py**.

## animals.py
> Код класса [animals.py](animals.py).
```python
# Класса Mammal представляет род млекопитающих


class Mammal:

    # Метод принимает аргумент для 
    # вида млекопитающего
    def __init__(self, special):
        self.__special = special

    # Метод показывает сообщение 
    # о виде млекопитающего
    def show_special(self):
        print(f'Я - {self.__special}')

    # Метод издает звук характерный для
    # млекопитающего
    def make_sound(self):
        print('Гррррр')
```
В коде мы инициализировали атрибуты данных и методы-мутаторы/методы-получатели.
Взгляем на использовани и вывод класса в программе **animals_demo.py**

> Код программы [animals_demo.py](animals_demo.py).
```python
# Демонстрация работы полиморфизма

import animals

mammal = animals.Mammal('обычное млекопитающее')
mammal.show_special()
mammal.make_sound()
```
Вывод:
```
Я - обычное млекопитающее
Гррррр
```
Все работает как и должно работать, теперь дополним **animals.py** классом  **Dog**, который является подклассом **Mammal**.

## Подкласс Dog.
> Код класса [animals.py](animals.py).
```python
# Класс Dog является подклассом класса Mammal


class Dog(Mammal):

    # Метод __init__ вызывает метод __init__
    # надкласса, передавая 'собака' в качестве вида.
    def __init__(self):
        Mammal.__init__(self, "собака")

    # Метод make_sound переопределяет метод
    # make_sound надкласса.
    def make_sound(self):
        print("Гав-гав!")
```
В коде мы переопределяем нужные под конкретный подкласс методы, используя полиморфизм. При этом методы в надклассе выполняют необходимую для них роль в надклассе не меняясь.

Взгляем на использовани и вывод класса в программе animals_demo.py
> Код программы [animals_demo.py](animals_demo.py).
```python
# Демонстрация работы полиморфизма

import animals

mammal = animals.Mammal('обычное млекопитающее')
mammal.show_special()
mammal.make_sound()
print()

dog = animals.Dog()
dog.show_special()
dog.make_sound()
```
Вывод:
```terminal
Я - обычное млекопитающее
Гррррр

Я - собака
Гав-гав!
```
Как видно, полиморфизм метода **init** и **make_sound** в подклассе **Dog** никак не повлиял на методы в надклассе **Mammal**.

## Подкласс Cat
> Код класса [animals.py](animals.py).
```python
# Класс Cat является подклассом класса Mammal


class Cat(Mammal):

    # Метод __init__ вызывает метод __init__
    # надкласса, передавая 'кот' в качестве вида.
    def __init__(self):
        Mammal.__init__(self, "кот")

    # Метод make_sound переопределяет метод
    # make_sound надкласса.
    def make_sound(self):
        print("Мяу!")
```
Класс переопределят так же как и Dog методы **init** и **make_sound**.

---

Как видно из примеров. Полиморфизм позволяет выполнять варианты методов тех подклассов, в которых они записаны не влияя на методы определенные изначально в надклассе.
