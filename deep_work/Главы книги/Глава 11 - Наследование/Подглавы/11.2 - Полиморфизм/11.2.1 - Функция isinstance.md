# 11.2.1 - Функция isinstance.

Полиморфизм обеспечивает большую гибкость при разработке программы. Например можно разработать функцию, которая принимает в себя аргуметом объект и затем использует методы надкласса. Пример этого в **polimorphism_demo.py**

## polimorphism_demo.py
> Код программы [polimorphism_demo.py](polimorphism_demo.py).
```python
# Программа демонстрирует полиморфизм

import animals


def main():
    # Создать объект Mammal, Dog
    # и Cat
    mammal = animals.Mammal("это обычное животное")
    dog = animals.Dog()
    cat = animals.Cat()

    # Показать информацию о каждом животном
    print("Вот несколько животных издают и")
    print("звуки, которые они издают.")
    print("--------------------------")
    show_mammal_info(mammal)
    print()
    show_mammal_info(dog)
    print()
    show_mammal_info(cat)


# Функция show_mammal_info принимает объект
# в качестве аргумента и вызывает свои методы
# show_special и make_sound
def show_mammal_info(creature):
    creature.show_special()
    creature.make_sound()


if __name__ == "__main__":
    main()
```
Вывод:
```terminal
Вот несколько животных издают и
звуки, которые они издают.
--------------------------
Я - это обычное животное
Гррррр

Я - собака
Гав-гав!

Я - кот
Мяу!
```
Однако если передать в функцию объект, который не является млекопитающим? Это демонстрирует программа **wrong_type.py**.

## wrong_type.py
> Код программы [wrong_type.py](wrong_type.py).
```python
def main():
    # Передать символьные значения в функцию show_mammal_info
    show_mammal_info("Я - последовательность символов.")


# Функция show_mammal_info принимает объект
# в качестве аргумента и вызывает свои методы
# show_special и make_sound
def show_mammal_info(creature):
    creature.show_special()
    creature.make_sound()


if __name__ == "__main__":
    main()
```
Вывод:
```terminal
AttributeError: 'str' object has no attribute 'show_special'
```
При данном случае появляется исключение **AttributeError**(Ошибка атрибута), потому что строковый тип данных не имеет метода под названием show_special()

Появление исключения можно предотвратить при помощи встроенной функции **isinstance**. Её применяют для определения, является ли объект экземпляром конкретного класса или подклассом этого класса.

Общий форма функции:
> isinstance(объект, класс)

В данном формате **объект** - ссылка на объект, **класс** - имя класса. Если объект, который ссылается на **объект**, является экземпляром **класса** или **подкласса**, то эта функция возвращает True, иначе возвращает False.

Программа **polimorphism_demo2.py** демонстрирует это

## polimorphism_demo2.py
> Код программы [polimorphism_demo2.py](polimorphism_demo2.py).
```python
# Программа демонстрирует полиморфизм

import animals


def main():
    # Создать объект Mammal, Dog
    # и Cat
    mammal = animals.Mammal("это обычное животное")
    dog = animals.Dog()
    cat = animals.Cat()

    # Показать информацию о каждом животном
    print("Вот несколько животных издают и")
    print("звуки, которые они издают.")
    print("--------------------------")
    show_mammal_info(mammal)
    print()
    show_mammal_info(dog)
    print()
    show_mammal_info(cat)
    print()
    show_mammal_info("Я - последовательность символов.")


# Функция show_mammal_info принимает объект
# в качестве аргумента и вызывает свои методы
# show_special и make_sound
def show_mammal_info(creature):
    if isinstance(creature, animals.Mammal):
        creature.show_special()
        creature.make_sound()
    else:
        print("Это не млекопитающее")


if __name__ == "__main__":
    main()
```
Вывод:
```terminal
Вот несколько животных издают и
звуки, которые они издают.
--------------------------
Я - это обычное животное
Гррррр

Я - собака
Гав-гав!

Я - кот
Мяу!

Это не млекопитающее
```
Как видно, функция не вызвала исключение, а вывело текст который выводится в случае исключения.
