# 10.2.4 - Класс BankAccount

Тут будет рассмотрен пример класса BankAccount сохраненного в модуле bankaccount.

Объект будет имитировать банковские счета, позволяя иметь начальный остаток, вносить вклады, снимать суммы со счета и получать текущий остаток.

## bankaccount.py
```Python
# Класс BankAccount имитирует банковский счет

class BankAccount:

    # Метод __init__ применяет аргумент
    # с остатком на счете.
    # Он присваивается атрибуту __balance

    def __init__(self, bal):
        self.__balance = bal

    # Метод deposit вносит
    # на счет вклад

    def deposit(self, amount):
        self.__balance += amount

    # Метод withdraw снимает сумму 
    # со счета

    def withdraw(self, amount):
        if self.__balance >= amount:
            self.__balance -= amount
        else:
            print('Ошибка: Недостаточно средств')

    # Метод get_balance возвращает
    # остаток средств на счете

    def get_balance(self):
        return self.__balance
```

- Метод **init** принимает аргументами переменные: **self** и **bal**.
Параметр **bal** принимает начальный остаток на расчетном счете.
- Метод **deposit** принимает аргументами переменные: **self** и **amount**.
Параметр **amount** принимает вносимую сумму на баланс.
- Метод **withdraw** принимает аргументами переменные: **self** и **amount**.
Если баланс на счете больше или равен сумме которую хотят списать, то сумма списывается. Если меньше то сообщается о недостатке средств.
- Метод **get_balance** возвращает текущее значение атрибута __balance.

>Программа account_test.py демонстрирует это.

## account_test.py
```Python
# Программа демонстрирует работу класса BankAccount

import bankaccount

def main():
    # Получить начальный остаток
    start_bal = float(input('Введите начальный остаток: '))

    # Создать объект BankAccount
    saving = bankaccount.BankAccount(start_bal)

    # Внести на счет ЗП пользователя
    pay = float(input('Сколько Вы получили на этой неделе? '))
    print('Вношу эту сумму на Ваш счет...')
    saving.deposit(pay)

    # Показать остаток
    print(f'Ваш остаток на счете составляет ${saving.get_balance():,.2f}.')

    # Получить сумму для снятия с банковского счета
    cash = float(input('Какую сумму Вы желаете снять со счета? '))
    print('Снимаю эту сумму с Вашего банковского счета...')
    saving.withdraw(cash)

    # Показать остаток
    print(f'Ваш остаток на счете составляет ${saving.get_balance():,.2f}.')

if __name__ == '__main__':
    main()
```
- **start_bal** - присваивает начальный остаток счета пользователя и передается аргументом в метод **init**.
- **saving = bankaccount.BankAccount** - создает экземпляр класса BankAccount и присваивает переменной saving.
- **pay** - присваивает переменной ЗП пользователя и передает аргументом в метод **deposit**.
- **cash** - присваивает переменной сумму желаемую быть снятой со счета пользователем и передается аргуметом в метод **withdraw**.
