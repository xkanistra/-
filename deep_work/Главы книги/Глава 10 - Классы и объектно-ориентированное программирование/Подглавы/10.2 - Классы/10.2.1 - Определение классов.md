# 10.2.1 - Определение классов
Для создания классов необходимо написать **определение класса** - набор инструкций, которые задают *методы класса* и *атрибуты данных*. 
Например мы хотим создать программу имитации игры броска монеты. В программе мы неоднократно имитируем подбрасывание монеты и определяем всякий раз при приземлении выпадает орел или решка. Принимая объектно-ориентированный подход мы напишем *класс Coin*, который будет выполнять действий монетки.

> Пример работающего кода в программе coin_demo.py
```python
# Программа имитирует подбрасывание монетки при помощи класса Coin

import random

# Класс Coin имитирует монету, которую можно подбрасывать

class Coin:

    # Метод __init__ инициализирует
    # атрибут данных sideup значением 'Орел'
    def __init__(self):
        self.sideup = 'Орел'

    # Метод toss генерирует случайное число
    # в диапазоне от 0 до 1. Если это число   
    # равно 0, то sideup получает значение 'Орел'.
    # В противном случае sideup получает значение 'Решка'.

    def toss(self):
        if random.randint(0, 1) == 0:
            self.sideup = 'Орел'
        else:
            self.sideup = 'Решка'

    # Метод get_sideup возвращает значение,
    # на которое ссылается sideup

    def get_sideup(self):
        return self.sideup

# Главная функция
def main():
    # Создать объект на основе класса Coin
    my_coin = Coin()

    # Показать обращенную вверх сторону монеты
    print('Эта сторона обращена вверх:', my_coin.get_sideup())

    # Подбросить монету
    print('Подбрасываю монету...')
    my_coin.toss()

    # Показать обращенную вверх сторону монеты.
    print('Эта сторона обращена вверх:', my_coin.get_sideup())

if __name__ == '__main__':
    main()
```

## Как устроен класс Coin?
Класс Coin имеет три метода:
- метод __init__()
- метод toss()
- метод get_sideup()
**Методы похожи на определение функции** в Python. Они начинаются с **заголовка**, после которой идет выделенный отсутпом блок инструкций.

### Параметрическая переменная **self**, её назначение и важность.
Параметр **self** имеется в каждом методе класса Coin:
- def __init__(**self**)
- def toss(**self**)
- def get_sideup(**self**)

> Параметр **self** требуется в каждом методе класса. Метод оперирует **атрибутами данных** конкретного объекта и во время использования метод должен знать, атрибутами данных какого объекта он призван оперировать. Именно для этого служит параметр **self**, когда метод вызывается Python делает так, что параметр **self** ссылается на конкретный объект, которым призван оперировать метод.

### Метод __init__.
```python
def __init__(self):
    self.sideup = 'Орел'
```

Метод **__init__** называется **методом инициализации** - он инициализирует атрибуты данных объекта.
После создания объекта в ОЗУ исполняется метод __init__() и параметру **self** автоматически присваивается объект, который был только что создан.
>В результате выполнения метода каждый объект созданный на основе класса Coin будет первоначально иметь атрибут *sideup* с значением *'Орел'*.

### Метод toss().
```python
def toss(self):
    if random.randint(0, 1) == 0:
        self.sideup = 'Орел'
    else:
        self.sideup = 'Решка'
```

Метод **toss** так же имеет параметр **self** и при вызове данного метода **self** будет автоматически ссылаться на объект, которым метод будет оперировать.
>В результате выполнения метода инструкция *if* вызывает функцию *random.randint* для получения случайного числав диапазоне от 0 до 1. 
>Если число 0, то атрибуту *self.sideup* присваивается значение *'Орел'*, если число 1, то атрибуту *self.sideup* присваивается значение *'Решка'*.

### Метод get_sideup().
```python
def get_sideup(self):
        return self.sideup
```

Метод **get_sideup** так же имеет **self**. Он вызывается когда необходимо узнать какой стороной обращена монета.

>В результате выполнения метода просто возвращается текущее значение атрибута *self.sideup*.
