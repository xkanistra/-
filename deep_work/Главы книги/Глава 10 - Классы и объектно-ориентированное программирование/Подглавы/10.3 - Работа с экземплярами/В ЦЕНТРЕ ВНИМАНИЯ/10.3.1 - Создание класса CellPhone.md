# 10.3.1 - Создание класса CellPhone.

**ТЗ**: Необходимо разработать класс, который представляет сотовый телефон.

Данные которые будут храниться в атрибутах класса:
- Имя производителя телефона: **__manufact**;
- Номер модели телефона: **__model**;
- Розничная цена телефона: **__retail_price**.

Класс будет иметь приведенные ниже методы:
- Метод **__init __()** - принимает аргументы для производителя, номера модели и розничной цены;
- Метод **set_manufact()** - принимает аргумент для модели телефона, и в случае необходимости позволит изменять значение атрибута **__model** после создания объекта;
- Метод **set_retail_price()** - принимает аргумент для розничной цены, и в случае необходимости позволит изменять значение атрибута **retail_price** после создания объекта; 
- Метод **set_model()** - принимает аргумент для модели телефона, и в случае необходимости позволит изменять значение атрибута **__model** после создания объекта;
- Метод **get_manufact()** - возвращает название производителя телефона;
- Метод **get_model()** - возвращает номер модели телефона;
- Метод **get_retail_price()** - возвращает розничную цену телефона.\

> В программе cellphone.py показано определение класса, сохраненного в модуле cellphone.

## cellphone.py
```python
# Класс CellPhone содержит данные о сотовом телефона

class CellPhone:

    # Метод __init__ инициализирует атрибуты

    def __init__(self, manufact, model, price):
        self.__manufact = manufact
        self.__model = model
        self.__retail_price = price

    # Метод set_manufact принимает аргумент для
    # производителя телефона

    def set_manufact(self, manufact):
        self.__manufact = manufact

    # Метод set_model() принимает аргумент для
    # номера модели телефона

    def get_model(self, model):
        self.__model = model

    # Метод set_retail_price() принимает аргумент для
    # для розничной цены телефона

    def set_retail_price(self, price):
        self.__retail_price = price

    # Метод get_manufact() возвращает
    # производителя телефона

    def get_manufact(self):
        return self.__manufact

    # Метод get_model() возвращает
    # номер модели телефона

    def get_model(self):
        return self.__model

    # Метод get_retail_price() возвращает
    # розничную цену телефона

    def get_retail_price(self):
        return self.__retail_price
```

# Программа тестирует работу класса CellPhone

import cellphone

def main():
    # Получить данные о телефоне
    man = input('Введите производителя: ')
    mod = input('Введите номер модели: ')   
    retail = float(input('Введите розничную цену: '))

    # Создать экземпляр класса CellPhone

    # Показать введенные данные

    print(f'Модель: {phone.get_model()}')
    print(f'Розничная цена: {phone.get_retail_price():,.2f}')
    
if __name__ == '__main__':
    main()

## Методы-получатели и методы-мутаторы.
Широко в практике применяется делать в классе все атрибуты приватными, чтобы избежать возможных изменения данных в классе кодом из вне, у таких методов есть свое название:
- **Метод-получатель** - возвращает значени из атрибута класса при этом не изменяет его. В примере это: **get_manufact()**, **get_model()**, **get_retail_price()**;
- **Метод-мутатор** - сохраняет значение в атрибуте данных либо каким-нибудь иным образом изменяет значение атрибута данных. В примере это: **set_manufact()**, **set_retail_price()**, **set_retail_price()**.
