# 10.3.0 - Работа с экземплярами
>Каждый экземпляр класса имеет собственный набор атрибутов данных.

Это значит, что при использовании параметра метода **self** для создания атрибута, этот атрибут пренадлежит конкретному объекту, на который ссылается параметр **self**.

Их называют - **атрибутами экземпляра**, т.к они принадлежат только одному конкретному экземпляру класса. В программе можно создавать многочисленный экземпляры одного и того же класса и каждый будет иметь свой собственный набор атрибутов.

> В программе coin_demo5.py демонстрируется данная особенность.

## coin_demo5.py
```python
# Эта программа импортирует имитационный модуль
# и создает три экземпляра класса Coin

import coin

def main():
    # Создать 3 объекта класса Coin
    coin1 = coin.Coin()
    coin2 = coin.Coin()
    coin3 = coin.Coin()

    # Показать повернутую вверх сторону каждой монеты
    print('Вот три монеты, у которых эти стороны обращены вверх: ')
    print(coin1.get_sideup())
    print(coin2.get_sideup())
    print(coin3.get_sideup())

    # Подбросить монету
    print('Подбрасываю монету...')
    print()
    coin1.toss()
    coin2.toss()
    coin3.toss()

    # Показать повернутую вверх сторону каждой монеты
    print('Теперь обращены вверх вот эти стороны: ')
    print(coin1.get_sideup())
    print(coin2.get_sideup())
    print(coin3.get_sideup())
    print()

if __name__ == '__main__':
    main()
```
