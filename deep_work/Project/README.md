# 🐍 Мой путь в Python

Обучение по книге Тони Гэддиса «Начинаем программировать на Python».

## Структура
- `Главы книги` — конспекты глав  
- `Project` — микро-проекты  
- `uprajnenia` — упражнения из книги

## Проекты.

### Калькулятор(Главы 2 - 4)
- Файл: Pet_project/Калькулятор/Calculator_cikle_validation.py
- Возможности: +, -, x, /, валидация деления на 0, повторный запуск.
- Использует 'while', условия, флаги.

### Угадай число UPD(Главы 2 - 4)
- Файл: Pet_project/Игра угадай число/game_ugadai_chislo_validation_cikle.py
- Загадано конктреное число, присутсует счетчик попыток UPD: добавлен ограничитель попыток.
- Использует 'while/for', счетчик, сравнения, валидацию.

### Рисование фигур по выбору(Глава 2 - 4)
- Файл: Pet_project/Рисование фигур по выбору/turtle_wibor_cikle_walidation.py
- Рисует фигуры по выбору через меню.
- Использует: turtle, циклы, валидацию

### Конвентер(Глава 2 - 3)
- Файл: Pet_project/Конвертер/conventer.py
- Переводит из градусов С <-> F, из м <-> см через выбор в меню.
- Использует: if-elif-else.

### Анкета(Глава 2 - 3)
- Файл: Pet_project/Анкета/personal_anketa.py
- Создает анкету и дает совет исходя из возраста.
- Использует: if-elif-else, сравнения.

### Счетчик шагов(Глава 2 - 4).
- Файл: Pet_project/Счетчик шагов/steps_traker.py
- Считает выполненные шаги за неделю, среднее кол-во, сколько дней шагов было больше 10000 и выводит поздравление при достижении определенной цели.
- Использует: Цикл for, if-else, расширенные операторы присваивания.
- Есть блок-схема проекта.

### Таблица умножения (Глава 2 - 4)
- Файл: Pet_project/Таблица умножения/table_multiplication.py
- Запрашивает у пользователя размер таблицы и выводит таблицу в качестве сетки
- Использует: цикл for, вложенные циклы
- Есть блок-схема проекта.

### Черепашья галерея фигур (Глава 2 - 4)
- Файл: Pet_project/Черепашья галерея фигур/turtle_galery.py
- Выводит меню выбора, далее через валидацию проверяет условие ввода, внутри цикла if-elif-else, рисуются фигуры через циклы.
- Использует: циклы while/for, валидацию данных, if-elif-else, turtle.
- Есть блок-схема проекта.

### Бюджетный калькулятор недели (Глава 2 - 4)
- Файл: Pet_project/Бюджетный калькулятор недели/turtle_galery.py
- Программа расчитывает бюджет пользователя на неделю и позволяет отслеживать ежедневные траты, понимать укладывается ли он в бюджет
- Использует: цикл for, накапливающую переменную, if-else, f-строку.
- Есть: Алгоритм в виде псевдокода и блок-схема проекта.
