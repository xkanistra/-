# sales-commission-calculator
Полностью задокументированный Python-проект: расчёт месячной выплаты продавцу с учётом объёмов продаж, ступенчатой комиссии и аванса. Включает псевдокод, блок-схемы, таблицы ВОВ и анализ потока данных.

# 📊 Калькулятор комиссионных продаж

Чистый и полностью задокументированный Python-проект для расчёта месячной выплаты продавцу на основе:
- Объёма продаж за месяц  
- Ступенчатой ставки комиссионных  
- Авансового платежа  

Проект создан на основе примера из книги *«Начинаем программировать на Python»* Тони Гэддиса — но значительно расширен системной документацией.

---

## 📋 Возможности
- ✅ Модульная структура: `main()`, `get_sales()`, `get_advanced_pay()`, `determine_comm_rate()`
- ✅ Базовая проверка входных данных
- ✅ Обработка отрицательной выплаты (продавец должен возместить разницу)
- 📐 Полная документация:
  - Псевдокод
  - Блок-схема (`.drawio`)
  - Таблицы «Ввод → Обработка → Вывод» для каждой функции
  - Таблица ставок комиссионных
  - Схема передачи данных между функциями
